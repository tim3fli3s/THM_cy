# TryHackMe Cybersecurity Writeups

This repository documents practical cybersecurity learning through TryHackMe rooms and labs.

The writeups focus on:

- Enumeration methodology
- Commands and their purpose
- Troubleshooting and lessons learned
- Security risks and vulnerabilities
- Detection and remediation recommendations

> Flags, passwords, and direct quiz answers are excluded where appropriate.

## Writeups
Writeups will be added as I progress through the TryHackMe learning paths.
